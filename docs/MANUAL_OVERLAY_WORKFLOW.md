This branch has not been merged into `main`.

## Required workflow and invariants

A manually marked missed face is tracked independently of Auto detections and other manual faces. Each face owns a stable GUID, editable alpha, correction keyframes, validated motion samples, and failure boundaries. Correcting face A cannot remove face B's track. An absent motion sample must not reuse a stationary earlier mask. Preview and export combine current-frame Auto, retained legacy manual coverage, and all confirmed face-specific coverage. Invalid persisted target data and unresolved target gaps must not produce an apparently successful unblurred export.

## Change log — 2026-09-21: further lifecycle, retry and safety changes (unverified)

### Retry status reflects retained coverage

- **Why:** A rejected shorter or failing retrack could be reported using the *attempted* segment even though the workspace retained a longer previous segment.
- **What:** `ManualOverlayTargetTrackingService.TrackForward` now retrieves the actual retained, fingerprint-matching segment after `SetTrackSegment` and returns that saved segment and its frame count. It rejects an explicitly all-zero tracking source. [`33fd5ae`](https://github.com/doanythingK/FaceShield_/commit/33fd5aee00450053f7f1132abac942bca38eecf8).
- **Verification:** Deferred; no build, tracking invocation or source video run. Cancellation versus saving still needs careful lifecycle review.

### Optional selection data cannot abort workspace open

- **Why:** `ManualOverlayTargetSelectionStore.Load` resolved the video-derived metadata path **outside** its error handler; a missing/invalid path could abort otherwise valid target-state opening.
- **What:** Path resolution is now inside the optional metadata error boundary, and temporary selection-file cleanup does not mask the original save exception. It still rejects source-evidence mismatches and unknown selection IDs. [`a426524`](https://github.com/doanythingK/FaceShield_/commit/a426524eeefa65c270d59b45cdbb3258fcc807b3).
- **Verification:** Deferred; no invalid-path test or GUI restart was run.

### Toolbar save, programmatic timeline selection and playback startup

- **Why:** `FramePreviewViewModel.PersistCurrentMask()` can write a dirty selected-target bitmap into the **legacy global manual layer** if invoked before target-owned persistence. UI-only pointer/keyboard hooks did not cover programmatic `FrameList.SelectedFrameIndex` updates, or playback start. A target save failure could then clear the editor without saving its face-owned alpha.
- **What:** `WorkspaceView.axaml.cs` now configures the existing synchronous `ToolPanel.ManualTargetExportGuard` to commit target-owned edits before the toolbar Save command invokes `WorkspaceViewModel.OnSaveRequested`; it also archives Undo at pointer entry and disconnects the view-bound guard on detach or workspace switch. [`0fc996f`](https://github.com/doanythingK/FaceShield_/commit/0fc996f65257b7e4cb14286654b2dfd162064c35).
- **What (central event owner):** `WorkspaceSessionPlaybackCoordinator` now commits pending selected-target edits and archives Undo before dispatching both UI and programmatic `FrameList` selection changes, and before starting playback. If the target state cannot be saved, it stops the navigation, tries to restore the previous selected frame, and displays the save failure instead of dispatching a legacy global save. The rejected-playback path suppresses cleanup that would otherwise erase the editable bitmap/Undo stack. [`88521b3`](https://github.com/doanythingK/FaceShield_/commit/88521b335673c474b7ff138948eec08963d2d940), [`78c0b77`](https://github.com/doanythingK/FaceShield_/commit/78c0b774237170eab9e1939b2f1ecb03319ce69d).
- **What (source consistency):** `FramePreviewViewModel.ManualTargetUi.cs` now exposes `ManualTargetEditableFrameIndex` used by the UI and coordinator to identify the old editor frame on a failed navigation. Removed its outdated `CanExportLegacyMask` blocker now that the target export adapter is connected. [`9d56796`](https://github.com/doanythingK/FaceShield_/commit/9d56796592cd6058f711902eb9e4cb99af8757d9).
- **Verification:** **Deferred by user request.** No compilation, regression, Actions results, GUI interaction, or rendered output is claimed for these commits. The changes are source-level safeguards, not demonstrated runtime guarantees.
- **Remaining:** `FramePreviewViewModel.PersistCurrentMask()` itself still has the legacy global writer and can be called directly by other paths. Direct `FramePreviewViewModel.OnFrameIndexChanged`, exceptional disposal, asynchronous session startup, and alternative programmatic export entry points are not all covered by the new coordinator. The optional view-based Save guard is disconnected if its view is not attached. Move target ownership into the view-model's central persistence method before marking all edit-loss paths resolved. A save failure may still surface via an uncaught GUI event outside the coordinator.
