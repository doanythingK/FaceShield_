# Manual overlay and tracking — implementation status

Working branch: `refactor/manual-overlay-workflow`. **All changes dated 2026-09-21 remain unbuilt and untested at the user's request.** A source commit is not evidence of correct compilation, GUI operation, tracking accuracy, complete data preservation or correct encoded output. Changes have not been merged into `main`.

## Required workflow and invariants

Each manually identified missed face has a stable GUID, its own editable alpha, explicit correction keyframes, validated motion samples and failure boundaries. Correcting face A must not erase face B's track. A missing motion sample must not be replaced by a stationary held mask. Preview and export should combine current-frame Auto coverage, separate legacy/global manual coverage and all confirmed face-specific coverage. Malformed saved target state or unresolved nonempty target gaps must not yield apparently successful unblurred exports. Legacy/global masks must never acquire inferred face IDs.

## Change log — 2026-09-21; no build, tests, CI, GUI or exported-video verification

### Save guards, playback and Auto

- **Reason:** Dirty selected-face alpha could reach the legacy/global `FramePreviewViewModel.PersistCurrentMask` writer. GUI-only hooks did not protect programmatic `FrameList` selection or playback, and save failures could clear the editor.
- **Changes:** The view commits target edits before toolbar Save and pointer/keyboard navigation. `WorkspaceSessionPlaybackCoordinator` commits and archives Undo before `FrameList` transitions and playback; it rejects navigation on save failure, attempts to revert frame selection and avoids clearing the rejected playback editor. [`0fc996f`](https://github.com/doanythingK/FaceShield_/commit/0fc996f65257b7e4cb14286654b2dfd162064c35), [`88521b3`](https://github.com/doanythingK/FaceShield_/commit/88521b335673c474b7ff138948eec08963d2d940), [`78c0b77`](https://github.com/doanythingK/FaceShield_/commit/78c0b774237170eab9e1939b2f1ecb03319ce69d), [`9d56796`](https://github.com/doanythingK/FaceShield_/commit/9d56796592cd6058f711902eb9e4cb99af8757d9).
- `TryCommitPendingManualTargetEdit()` reports failures while leaving dirty pixels available; the view blocks relevant input/Save on failure, and `ToolPanelViewModel.SetAuto` checks the same guard. The target Auto lifecycle attempts to restore selected-face editing and archived Undo after the older global Auto refresh. [`25bcd68`](https://github.com/doanythingK/FaceShield_/commit/25bcd681e9783f05ae262066cc37d0a327cd4307), [`c09564a`](https://github.com/doanythingK/FaceShield_/commit/c09564acbad634a7292c31071c3ce80ddad63f05), [`3aa2bde`](https://github.com/doanythingK/FaceShield_/commit/3aa2bde3e32c56313686d75e0799947bad60e695), [`79119e9`](https://github.com/doanythingK/FaceShield_/commit/79119e9d055fd01da985c25b07a116454068842f).
- **Limit:** `PersistCurrentMask()` itself remains a legacy/global writer. Direct preview frame loads, session replacement and disposal are not centrally protected. A direct programmatic Export can bypass a view- or command-based preflush. No save-failure/Auto GUI behavior has been exercised.

### Tracking, corrections and target creation

- **Reason:** Live `SetTrackSegment` or `SetExplicitKeyframe` followed by a failed file write could make preview differ from export. Shorter or empty retracks could be reported instead of a retained verified interval.
- **Changes:** The target tracker first completed a previously cancellable mutation/save sequence ([`3925d48`](https://github.com/doanythingK/FaceShield_/commit/3925d483333cb22cc77e42350eecfc82bc7720f4)); subsequent implementation stages and atomically saves the candidate document *before* publishing a live track, verifies fingerprint and correction boundary, and reports the effective retained track. It does not relabel a late committed result as an unsuccessful cancellation. An empty retry retains a previous same-source segment if available. [`33fd5ae`](https://github.com/doanythingK/FaceShield_/commit/33fd5aee00450053f7f1132abac942bca38eecf8), [`8b61f25`](https://github.com/doanythingK/FaceShield_/commit/8b61f255ceed0bc96262a64fae1a3297bf50700a), [`0ea5b5d`](https://github.com/doanythingK/FaceShield_/commit/0ea5b5d878b4363039c580f3b9b4302c3aa60d92), [`89f2c62`](https://github.com/doanythingK/FaceShield_/commit/89f2c629584e488df288404e291373ab6d2e4a1d).
- `ManualOverlayTargetEditCommitter` stages a same-face correction and track truncation, writes the target document first, then publishes the live keyframe. Selection setters and face creation own Undo archive/restore; brush/Undo callbacks report a failed correction write without throwing away dirty pixels. Creation saves a detached candidate before replacing the live face list; optional selected-ID load failure is nonfatal. [`7564a93`](https://github.com/doanythingK/FaceShield_/commit/7564a93aa6570e8a5c8d0c4a45c60da8633b89aa), [`1207366`](https://github.com/doanythingK/FaceShield_/commit/120736692f0a0e2f7873521024ba12e868002c2e), [`a426524`](https://github.com/doanythingK/FaceShield_/commit/a426524eeefa65c270d59b45cdbb3258fcc807b3), [`0ea5b5d`](https://github.com/doanythingK/FaceShield_/commit/0ea5b5d878b4363039c580f3b9b4302c3aa60d92), [`4768d2b`](https://github.com/doanythingK/FaceShield_/commit/4768d2b83675a00967f742b768065173430412c5), [`7088d6d`](https://github.com/doanythingK/FaceShield_/commit/7088d6d0b82dd90bb1ec7ba4b83423609466af2b).
- **Source correction:** An accidental change of the tightly packed `ExtractAlpha` destination from `y * width + x` to `y * rowBytes + x` was immediately reverted. [`bf2b591`](https://github.com/doanythingK/FaceShield_/commit/bf2b5911c3fb0e2fbefd0f5d8359945bacc7b978).

### Further in-process commit ownership and UI error handling (this update)

- **Reason:** Snapshot/file/live publication in two distinct operations could interleave when a background retrack and face correction use the *same* `ManualOverlayTargetWorkspace` instance. Also, an uncaught GUI new-face write error could escape the click event, and direct frame navigation could miss the latest Undo archive if it bypassed the view handlers.
- **Changes:** `ManualOverlayTargetEditCommitter.cs` now locks the workspace instance from snapshot through disk-first save and live correction publication ([`4109f1e`](https://github.com/doanythingK/FaceShield_/commit/4109f1e79888bd1ce2ca9e94abb191ceddd99a32)). `ManualOverlayTargetTrackingService.cs` takes the same instance lock after decode, rechecks source fingerprint and correction boundary, evaluates empty/rejected retries against the locked snapshot and performs disk-first publication as one in-process critical section ([`fa04a7f`](https://github.com/doanythingK/FaceShield_/commit/fa04a7f0c5fcfebd51ea0562dd50f5ada5ecc26e)).
- `FramePreviewViewModel.ManualTargetLifecycle.cs` additionally archives selected-face Undo on the brush-completion and Undo events and centralizes target operation failure status ([`7bb0808`](https://github.com/doanythingK/FaceShield_/commit/7bb0808d43632337dce229aba389d9ee8fc72cb6)). `WorkspaceView.axaml.cs` catches GUI new-face creation errors, retains the selected face and reports failure; it skips unnecessary Undo restoration if the command was a no-op ([`71b3070`](https://github.com/doanythingK/FaceShield_/commit/71b3070c53389444286324ba4575418e3cc72800)).
- **Verification:** Deferred by the user. No compilation, unit test, CI run, cancellation race, write failure injection, manual GUI, or encoded-video comparison was executed for these commits.
- **Limit:** `lock(workspace)` only serializes these two committers using the same object. New-face creation/reload, a second workspace instance or an external process is not included in this lock. The archive hooks need a configured selected face and do not persist unsaved alpha at disposal. Direct programmatic `CreateManualTargetCommand` calls outside this view can still throw. A tracker exception before returning zero samples can still show failure even if older verified coverage remains.

## Remaining implementation and verification

1. **Central edit ownership (highest priority):** Make `FramePreviewViewModel.PersistCurrentMask()` itself route an active selected face to target-owned persistence, never to `FrameMaskProvider.SetMask` / `SetIndependentManualMask`. Audit `OnFrameIndexChanged`, `LoadManualFrameAsync`, `EnsureCurrentManualFrameEditable`, session replacement, playback-stop and `Dispose` for save-failure preservation and per-frame Undo. Do not claim all data-loss routes are closed until these are addressed.
2. **File concurrency and export audit:** Serialize creation, correction and tracking with appropriate state ownership; prevent stale independent workspace/external writers from overwriting newer documents. Audit export calls outside `WorkspaceExportCoordinator` and direct programmatic Save/Auto entry points without inferring a legacy mask's face identity.
3. **Runtime and performance unknown:** Full-frame preview composites and repeated source fingerprints have unmeasured memory/latency, seeking, long-video and packaged FFmpeg characteristics.
4. **Deferred verification:** Only when the user resumes checks: compile, targeted A/B face correction and save-failure tests, frame/Undo/navigation/disposal failure tests, real multi-face GUI, decoded-preview versus encoded-output pixel parity, long-video tests and Windows/macOS build/package checks. **None of these have been run for the new implementation.**
