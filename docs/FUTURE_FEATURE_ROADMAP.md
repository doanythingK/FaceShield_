# Future Feature Roadmap

이 문서는 현재 YOLO 품질 안정화 이후 추가할 제품 기능 방향을 기록한다. 여기의 항목은 현재 자동 모자이크 품질 goal의 완료 조건이 아니며, 나중에 별도 기능 goal로 분리해서 구현한다.

## Target User

1차 대상은 유튜버와 소규모 영상 제작자다. 핵심 사용 시나리오는 클라우드 업로드 없이 로컬에서 촬영본을 열고, 공개해도 되는 사람은 제외하면서 나머지 얼굴을 빠르게 모자이크하는 것이다.

## Registered Person Exclusion

공개해도 되는 사람을 미리 등록하고, 자동 모자이크 중 해당 인물은 블러에서 제외한다.

- 사람별로 얼굴 사진 5~10장을 등록한다.
- 사진은 정면, 측면, 다른 표정, 다른 조명처럼 변형이 있는 샘플을 권장한다.
- 앱은 등록 사진에서 얼굴 임베딩을 생성해 로컬 프로젝트 또는 로컬 프로필에 저장한다.
- 영상 분석 중 검출된 얼굴 crop을 등록 인물 임베딩과 비교한다.
- 등록 인물로 충분히 높은 confidence가 나오면 해당 얼굴 track은 모자이크 제외 후보로 둔다.
- confidence가 낮거나 작은 얼굴, 측면 얼굴, motion blur, edge face는 기본적으로 모자이크 유지 또는 review 대상으로 둔다.
- 최종 export 전에 "모자이크 제외된 얼굴"과 "확인 필요 얼굴"을 사용자가 검수할 수 있어야 한다.

안전 기본값:

- 애매하면 블러한다.
- 등록 인물 제외는 고신뢰도에서만 자동 적용한다.
- 사용자가 한 프레임에서 인물 판단을 고치면 같은 track 또는 같은 person group 전체에 적용할 수 있어야 한다.

## Post-Auto Frequent Person Review

자동 모자이크가 끝난 뒤, 영상에 많이 등장한 사람을 그룹으로 보여주고 사용자가 블러 여부를 선택하게 한다.

- 자동 분석 결과의 face track들을 얼굴 임베딩 기준으로 person group으로 묶는다.
- 등장 프레임 수, 누적 화면 점유, 대표 crop 품질을 기준으로 많이 등장한 사람을 우선 표시한다.
- 각 person group은 대표 얼굴 썸네일 3~8장과 등장 구간 정보를 함께 보여준다.
- 사용자는 그룹별로 `블러`, `블러 제외`, `확인 필요`를 선택한다.
- 선택 결과는 같은 person group의 모든 track에 일괄 적용한다.
- 확신이 낮거나 서로 다른 사람이 섞였을 가능성이 있는 group은 자동 제외하지 않고 review 대상으로 둔다.

이 기능은 사전 등록 인물 기능과 같이 동작해야 한다.

- 사전 등록 인물: 유튜버 본인, 고정 출연자, 스태프처럼 항상 공개 가능한 사람을 미리 제외한다.
- 사후 등장 인물 선택: 게스트, 행인, 관객처럼 영상마다 달라지는 사람을 자동 그룹화 후 선택한다.
- 최종 검수: 블러 제외 처리된 얼굴만 빠르게 훑어서 미탐/오분류 위험을 줄인다.

## Technical Direction

- 얼굴 검출은 현재 `FaceONNX`/`YoloFaceOnnx` 경로를 재사용한다.
- 얼굴 track 안정화가 먼저 필요하므로, 이 기능은 현재 YOLO flicker/scene-carry/false-positive 안정화 이후에 진행한다.
- 얼굴 인식은 FaceONNX recognition 기능을 먼저 확인하고, 부족하면 ArcFace 계열 ONNX 임베딩 모델을 별도 후보로 검토한다.
- person group clustering은 track 단위 임베딩 평균, representative crop 품질 점수, temporal consistency를 함께 사용한다.
- 모델 파일과 임베딩 데이터는 라이선스와 개인정보 리스크가 있으므로 커밋하지 않는다.
- 로컬 처리와 로컬 저장을 기본 원칙으로 둔다.

## Product Positioning

판매 문구는 완전 자동 익명화 보장이 아니라, 유튜버용 로컬 AI 모자이크 편집 보조 도구로 잡는다.

예상 포지션:

> 공개할 사람은 등록해서 제외하고, 나머지 얼굴은 자동 모자이크한 뒤 빠르게 검수/수정하는 로컬 영상 편집 도구.

## Future Completion Criteria

이 기능을 구현할 때 최소 완료 조건은 다음으로 둔다.

- 등록 인물 1명당 5~10장 사진으로 로컬 임베딩 생성 가능
- 등록 인물 자동 제외 후보와 확인 필요 후보가 분리됨
- 자동 분석 후 많이 등장한 person group 목록이 표시됨
- group 단위 `블러`/`블러 제외` 선택이 workspace mask에 반영됨
- 애매한 후보는 기본적으로 블러 유지
- 최종 export 전 블러 제외 얼굴 검수 화면 또는 체크리스트 제공
- 짧은 샘플 clip 기준으로 오분류 후보 evidence와 수동 수정 경로가 문서화됨
